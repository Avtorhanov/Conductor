# Капот

Кнопка **</>** вверху открывает файлы текущего раздела. Править можно то, что расширяет Дирижёр; смотреть — всё остальное.

| Можно править | Только смотреть |
|---|---|
| навыки `skills/`, профили `profiles/`, справку `help/` | ядро `dirizher/core/` — порядок работы и защита |
| вопросы Штурмана `guide.yaml` | `config.yaml`, интерфейсы, помощники |
| лезвия `dirizher/plugins/*.py` | `_common.py` (сторож лезвий), симулятор |

Ядро закрыто намеренно: в нём копия «до», сверка и слово «ДА». Его меняют через git с тестами.

## Как сохранить

1. **Проверить** — YAML разбирается, профиль загружается так, как его загрузит ядро, код проходит сторожа и пробный импорт отдельным процессом.
2. **Сохранить** — для кода и профилей введите слово **ДА**: они влияют на работу с железом.
3. Правка вступает в силу сразу, без перезапуска.

## История и откат

Каждое сохранение кладёт прежнюю версию в историю (`data/hood/`). **История** → выбрать версию → **Вернуть**. Возврат — тоже правка с историей, его можно отменить. История не удаляется.

## Как открыть

Капот закрыт по умолчанию — кто знает код доступа, тот иначе мог бы менять код прибора.

- На экране самого прибора: «Прибор» → «Открыть капот» (до перезапуска).
- Насовсем: в `config.yaml` на приборе
  ```yaml
  hood:
    edit: true
  ```

## Сторож кода

Не пускает: удаление файлов, запуск программ в обход `self.run()`, `eval`/`exec`, запись из `probe()`, доступ к хранилищу копий. Это не песочница — сторож ловит ошибки, а не злой умысел.
