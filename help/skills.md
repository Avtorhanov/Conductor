# Навыки

Навык — папка `skills/<имя>/`, которая добавляет Дирижёру умение. Добавляется во вкладке **Навыки → +**, подхватывается без перезапуска.

| Вид | Когда | Что внутри |
|---|---|---|
| **Карта параметров** | прибор уже виден лезвию (например, Modbus RTU), нужно описать его настройки | `profiles/<имя>.yaml` — без кода |
| **Инструмент (протокол)** | у прибора свой протокол или нужна новая программа | `skill.py` — лезвие: available / probe / read / write |
| **Проверка** | новая диагностика дампа | `skill.py` с `@register` |

Всегда есть `skill.yaml` (паспорт) и `help.md` (справка навыка — появится в «Справке»).

## Структура

```
skills/thermo_trm/
  skill.yaml        id, title, kind, enabled, settings
  skill.py          код (для инструмента и проверки)
  profiles/*.yaml   профили и карты параметров
  help.md           справка
```

## Правила

- `probe()` только читает. Запись — только через ядро: копия «до», сверка, «ДА», копия «после».
- Порт или программа — отдельным процессом через `self.run([...])`. Образец помощника — `skills/modbus_rtu/rtu.py`.
- Лезвие нового навыка выключено: `settings: enabled: false`. Включайте, когда допишете.
- Каждая новая возможность — с тестом без железа (эмулятор или подставная программа), см. урок «Тесты без железа».

## Если навык сломался

Он не роняет систему: в «Навыках» будет причина. «Прибор» → «Самопроверка» вернёт последнюю рабочую версию из истории капота.
