# Своя статья справки

«Справка» → **+ Статья** → имя и название. Откроется капот с заготовкой.

```markdown
---
title: Роутер X1 — особенности
section: work          # где показывать первой: guide, work, log, dev, device
tags: [роутер, x1]
---
# Роутер X1

Коротко: зачем и когда.

1. Шаг.
2. Шаг.
```

Работает: заголовки `#`, списки, таблицы, **жирный**, `код`, блоки кода. Справка навыка — `help.md` в его папке.
