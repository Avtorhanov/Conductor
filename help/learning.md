# Как Дирижёр учится

Только проверенным знанием, не догадками:

- **Эталон** — дамп исправного устройства. По нему чинят такие же.
- **Отзыв** «заработало / нет» — способы ремонта, которые чаще помогали, предлагаются первыми.
- **Черновик профиля** — для незнакомого чипа; включается после вашей проверки.
- **Что помогло** — после неудачи (не опознано, не прочиталось, сверка не совпала) запишите одной фразой, что сделали. В следующий раз при такой же неудаче Дирижёр покажет это первым. Подтвердили ещё раз — подсказка поднимается выше.

Где записать: итог сеанса → «Записать, что помогло», или «Журнал» → сеанс → то же. «Сейчас важно» само напомнит, если после неудачи следующий сеанс прошёл.
