# Пример: сменить диапазон термодатчика

Задача: у преобразователя температуры диапазон 0…400 °C, нужен −50…600 °C. Прибор говорит по **Modbus RTU** через RS-485.

## 1. Подключение

USB–RS-485 переходник: **A → A, B → B**, GND по возможности. Прибор питается сам. Порт — обычно `/dev/ttyUSB0`, права — группа `dialout`.

## 2. Связь — навык «Modbus RTU»

«Навыки» → **Modbus RTU** → капот → `skill.yaml`:

```yaml
settings:
  enabled: true
  port: /dev/ttyUSB0
  baud: 9600          # как в меню прибора
  parity: N
  unit: 1             # сетевой адрес прибора
  model: THERMO-EXAMPLE
```

## 3. Карта параметров

Есть готовый пример `skills/modbus_rtu/profiles/thermo_example.yaml`. Для своего прибора: **Навыки → + → Карта параметров**, адреса регистров — из паспорта. Модель в карте (`match: name`) = `model` из шага 2.

## 4. Прочитать и сверить

«Штурман» → **Настроить прибор** → **Прочитать параметры**. Значения должны совпасть с экраном прибора. Не совпали — карта неверна, ничего не пишите.

## 5. Изменить

**Изменить параметры** → нижняя граница −50, верхняя 600 → **Записать** → **ДА**. Дирижёр снимет копию настроек, запишет только изменившиеся регистры, прочитает обратно и сверит.

## Если прибора нет в навыках

Свой протокол (не Modbus) — **Навыки → + → Инструмент (протокол)**: шаблон лезвия с подсказками. Нет описания протокола — Дирижёр не угадывает: нужен паспорт прибора или журнал обмена родной программы.
