# Настройки инструментов

Инструмент (лезвие) — это программа вроде flashrom или avrdude, которую Дирижёр вызывает сам. Пока вы его не
включили, он «выключен». Включают и настраивают формой — править файлы не нужно.

## Где

«Прибор» → «Инструменты» → нужный инструмент → «Настроить». В терминале — `python3 -m dirizher tool <имя>`.
Если переходника ещё нет под рукой — начните с «Прибор» → «Подключить инструмент»: выберите переходник,
Дирижёр покажет провода, права USB и ведёт к форме.

## Как работает форма

- Поля берутся из схемы лезвия: название, тип, пример, подсказка. У каждого видно, **откуда значение**:
  форма, `config.yaml`, навык или «по умолчанию».
- Поля про напряжение выделены предупреждением: ошибка здесь может испортить чип.
- «Проверить» ничего не записывает — только показывает, каким станет статус лезвия.
- «Сохранить» просит слово «ДА» и пишет файл `config.tools.yaml` (прежняя версия остаётся в истории капота).
  Пустое поле — убрать ключ: значение вернётся из `config.yaml` или по умолчанию.
- Опечатку в имени ключа Дирижёр заметит и подскажет верное («flash_sise — может быть, flash_size?»).

## Слои настроек

`config.yaml` (ваш ручной файл) < `config.tools.yaml` (форма) < поле `tool:` профиля чипа (модель из профиля).
Программа сама правит только `config.tools.yaml`; `config.yaml` остаётся вашим — там, например, `data_dir`,
`mirror_dir` и код доступа.

## Когда нужен капот

Сохранение настроек идёт через капот (история версий и «ДА»). Если он закрыт — «Прибор» → «Открыть капот» на экране
самого прибора. С телефона по умолчанию настройки можно смотреть и проверять, но не сохранять.

Справочник переходников и движков: `python3 -m dirizher catalog` (в браузере — вкладка «Справочник»).
