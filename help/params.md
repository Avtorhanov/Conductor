# Параметры прибора

**Настройка** меняет именованные параметры прибора — диапазон, уставку, адрес, единицы — по карте из профиля. Защита та же, что при ремонте: копия «до» → план «было → стало» → слово **ДА** → запись → сверка → копия «после». Откат — как обычно, из журнала.

## Как пользоваться

1. «Штурман» → **Настроить прибор** → **Прочитать параметры** (только чтение).
2. Сверьте значения с экраном прибора.
3. **Изменить параметры** → новые значения → **Записать** → **ДА**.

Командная строка: `python3 -m dirizher params` и `python3 -m dirizher tune --set range_high=600`.

## Карта в профиле

```yaml
bus: {start: 0, count: 16}       # окно чтения (для регистров Modbus)
params:
  - id: range_high
    title: Верхняя граница
    register: 2                   # или offset: 0x22 — смещение в байтах
    type: i16be                   # u8 i8 u16be u16le i16be i16le u32be u32le i32be i32le f32be f32le
    scale: 0.1                    # значение = число × scale
    unit: "°C"
    min: -50
    max: 600
    writable: true
    choices: {0: "°C", 1: "°F"}   # для перечислений
```

- Адреса, типы и пределы — **только из паспорта прибора**. Новая карта — «ПРОВЕРИТЬ НА ЖЕЛЕЗЕ»: сначала прочитать и сверить.
- В окно чтения включайте только **регистры настроек**. Измеряемые величины меняются сами — повторные чтения не совпадут, и запись заблокируется.
- Значение вне min/max, не по шагу или в «только чтение» — запись не начнётся.
