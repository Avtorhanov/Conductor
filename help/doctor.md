# Самопроверка

«Прибор» → **Самопроверка** (или `python3 -m dirizher doctor`). Дирижёр проверяет:

| Что | Чинит сам? |
|---|---|
| каждую копию дампа по SHA-256 — в основном месте и во втором (`mirror_dir`) | **да**: из исправного места; испорченный файл — в `data/quarantine/`, не удаляется |
| профили, навыки, лезвия, Штурман — загружаются ли | **да**, если правка была через капот: возврат последней рабочей версии |
| память SQLite | нет — только сообщает |
| место на диске, недоступные инструменты | нет — только сообщает |

Исправляет только то, что можно исправить без догадок, и только по вашей кнопке «Исправить» (или `doctor --heal`). Код и профили — со словом **ДА**.

Без второго места (`mirror_dir`) испорченную копию восстановить не из чего — включите его.
