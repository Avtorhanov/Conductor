# Учебная площадка

Пошаговый тренажёр: что можно сделать тем, что есть дома, и как это связано с Дирижёром. Ничего не записывает и не трогает железо.

**Открыть:** Штурман → «Учебная площадка», адрес `/playground.html` на приборе или в демо, в терминале — `python3 -m dirizher playground [маршрут]`.

| Маршрут | id | Уровень |
|---|---|---|
| Как думает Дирижёр (без железа) | `start` | 0 |
| Телефон, iPad | `phone`, `ipad` | 0 |
| Мультиметр, паяльник | `meter`, `solder` | 1 |
| Первая настоящая флешка (Pi + CH341A) | `first_chip` | 2 |
| Связки, что докупить | `combos`, `shop` | 2 |
| Ноутбук Acer Swift 3 (BIOS) | `laptop` | 3 |
| Лада Гранта (только чтение) | `car` | 4 |
| Телевизор LG | `tv` | 5 |
| Границы: чего не делаем | `limits` | 0 |

## Что в шаге

- объяснение простыми словами; подчёркнутые термины открывают **словарик**;
- **Зачем**, **В Дирижёре** (что нажать или какая команда), **Осторожно**, **Проверить на железе**;
- команды с кнопкой копирования, список «сделал»;
- **Что сделаете?** — вопрос с объяснением каждого ответа;
- **Сеанс вживую** — протоколы настоящего ядра на учебной микросхеме: выберите ситуацию (исправно, сбой обновления, плохой контакт, 1,8 В, план без записи) и посмотрите, что скажет Дирижёр.

Прогресс хранится в браузере (на этом устройстве). Тема и размер текста — как в Дирижёре.

## Отдельным файлом

`python3 -m dirizher playground --export тренажёр.html` — один файл со всеми маршрутами. Открывается в любом браузере без сети и без прибора: можно положить на диск, флешку, отправить почтой.

## Свой маршрут или шаг

Всё содержание — `dirizher/interface/playground.yaml` (капот → раздел «Штурман», без слова «ДА»: это учебный текст). Поля описаны в начале файла. Проверка — при сохранении в капоте или `python3 -m unittest tests.test_playground -v`: термины словарика, вопросы с верным ответом, ссылки между маршрутами, строки «сеанса вживую» сверяются с выводом настоящего ядра.
