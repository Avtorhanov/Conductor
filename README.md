# Дирижёр

Оркестратор диагностики и восстановления прошивок микросхем: сам определяет, что подключено, выбирает инструмент,
делает копию, сверяет и чинит по проверенному рецепту — **только с вашего «ДА»**. Внешние программы (flashrom,
probe-rs, minipro, avrdude, esptool…) вызываются отдельными процессами. Python 3.9+, из библиотек только PyYAML.

**Демо в браузере, без прибора:** https://avtorhanov.github.io/Conductor/ (на телефоне ставится как приложение).

```
подготовка → опознание → напряжение → копия «до» → диагностика → план → запись + сверка + копия «после» → отзыв
```

## Три команды, чтобы начать

```bash
python3 -m dirizher web                  # браузер: телефон, ПК, экран прибора (адрес и код напечатает)
python3 -m dirizher                      # то же в терминале: мастер-Штурман сам спрашивает, что дальше
python3 -m dirizher sim reset && python3 -m dirizher --sim run   # учебный запуск без железа
```

Железо подключают от переходника: «Прибор» → «Подключить инструмент» (или `connect`, `catalog`) — там провода,
права USB и настройки. Настройки инструментов — формой «Прибор» → «Инструменты» → «Настроить».

## Правила

- ничего не пишется без копии «до», сверки и вашего слова «ДА»; после записи — копия «после», откат всегда доступен;
- копии и данные в `data/` не удаляются и не правятся; уникальные данные платы (MAC, серийник) не затираются;
- защита от чтения и подписи прошивок не обходятся. Полный текст — [PRINCIPLES.md](PRINCIPLES.md).

## Команды

| Команда | Что делает |
|---|---|
| *(без команды)* или `wizard` | пошаговый мастер-Штурман в терминале |
| `web [--host H] [--port P]` | интерфейс в браузере: ПК, телефон, экран прибора |
| `plugins` | какие инструменты доступны |
| `tool [имя] [--set ключ=значение] [--check]` | настройки инструмента (лезвия): просмотр, проверка, сохранение после «ДА» |
| `profiles` | какие профили загружены |
| `connect [переходник]` | начать с переходника: проверки подключения (программа, правила USB, группы) |
| `detect` | только опознать (ничего не читает целиком) |
| `run [--dry-run] [--image F] [--label L]` | полный цикл |
| `history [-n 20]` | история сеансов |
| `show N` | подробности сеанса N: снимки, разделы, журнал |
| `journal N [--to F]` | журнал сеанса для разработки (без дампов, MAC и серийники заменены) |
| `feedback N --ok` / `--fail` | отзыв после проверки устройства (обучение) |
| `reference N [--kind before\|after] [--label L]` | сделать снимок сеанса эталоном |
| `rollback N [--dry-run]` | вернуть на чип копию «до» из сеанса N |
| `export N --kind before --to F` | выгрузить снимок в файл |
| `params` | прочитать параметры прибора по карте профиля (только чтение) |
| `tune --set id=значение [--dry-run]` | изменить параметры: копия «до», план, запись после «ДА», сверка |
| `skills` | навыки: что загружено, что сломано |
| `doctor [--heal]` | самопроверка: копии, память, профили, навыки |
| `catalog [id] [--kind engine\|adapter\|diy]` | справочник: переходники и движки |
| `playground [маршрут] [--export F]` | учебная площадка: тренажёр по маршрутам |
| `help [слово или имя]` | справка: список, поиск, статья целиком |
| `sim status\|reset\|corrupt\|erase\|flaky\|steady` | учебные поломки симулятора |

Перед командой можно добавить `--sim` (учебный режим) или `--config путь`.
