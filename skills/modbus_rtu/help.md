# Modbus RTU

Лезвие для приборов с настройками в регистрах: термопреобразователи, регуляторы, счётчики, частотники. Пример по шагам — статья «Пример: сменить диапазон термодатчика».

## Подключение

- Переходник USB–RS-485: **A → A, B → B**, общий GND по возможности. Прибор питается сам.
- Порт обычно `/dev/ttyUSB0`. Права: `sudo usermod -aG dialout $USER`, затем перелогиниться.
- Скорость, чётность и адрес — как в меню прибора.

## Настройки (капот → `skill.yaml` → `settings`)

| Ключ | Что |
|---|---|
| `enabled` | включить лезвие |
| `port`, `baud`, `parity`, `stopbits` | связь |
| `unit` | адрес прибора 1…247 |
| `model` | модель — по ней выбирается карта (`match: name`) |
| `write_function` | 6 — по регистру (понимают все), 16 — пачкой |
| `echo` | `true`, если переходник возвращает свои же байты |

Окно регистров (`bus: start, count, function`) задаётся в профиле прибора — только регистры **настроек**.

## Как устроено

Окно регистров — это «память» прибора: копия «до», сверка, копия «после», откат и эталон настроек работают как для микросхем. Запись — только изменившихся регистров. Связь — помощник `rtu.py` отдельным процессом.

## ПРОВЕРИТЬ НА ЖЕЛЕЗЕ

- Эхо вашего переходника (`echo`), паузы между кадрами на вашей скорости.
- Поддержку функции 16 прибором.
- Карту регистров `thermo_example.yaml` — она учебная, адреса придуманы.
