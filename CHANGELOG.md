# Журнал изменений

Формат: версия — дата — что изменилось. Новое лезвие повышает второе число версии (0.2.0, 0.3.0…).

## 0.1.0 — 2026-11-14
### Добавлено
- Ядро «Дирижёра»: сценарий опознание → напряжение → копия «до» → диагностика → план → запись со сверкой → копия «после» → отзыв.
- Хранилище копий по SHA-256: только чтение, проверка целостности, зеркало.
- Память в SQLite: сеансы, события, снимки, эталоны, статистика рецептов; текстовые журналы.
- Обучение: черновики профилей для незнакомых чипов, эталоны, рейтинг рецептов по отзывам.
- Профили чипов и плат (сигнатура в дампе, уникальные области `preserve`), общий профиль SPI NOR.
- Плагин `flashrom_spi`; плагин `simulator` с учебными поломками.
- Команды: plugins, profiles, detect, run, history, show, feedback, reference, rollback, export, sim.
- 12 автотестов на симуляторе.
- `tools/bundle.py` — весь код одним файлом для проекта в приложении Claude.
- Документация: README, PRINCIPLES, docs/START, docs/MANUAL, docs/SESSION_PROMPT, docs/STATUS, CLAUDE.md.
