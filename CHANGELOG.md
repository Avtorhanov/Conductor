# Журнал изменений

Формат: версия — дата — что изменилось. Новое лезвие повышает второе число версии (0.2.0, 0.3.0…).

## 0.4.0 — 2026-11-14 «Мастерская»
### Добавлено
- **Навыки** (`skills/<id>/`: паспорт, код, профили, справка) — новые протоколы, карты параметров и проверки
  без правки ядра; «Навыки» → «+» из шаблонов; подхватываются без перезапуска; сторож кода не пускает
  удаление файлов, процессы мимо `self.run()`, eval/exec, запись из `probe()`.
- **Капот** (`</>` в каждом разделе): код и настройки раздела в окне; правка навыков, профилей, лезвий,
  Штурмана и справки с проверкой (YAML, профиль, синтаксис, сторож, пробный импорт отдельным процессом),
  историей версий и возвратом; ядро и защита — только просмотр; слово «ДА» для кода и профилей;
  закрыт по умолчанию (экран прибора или `hood.edit: true`).
- **Справка** (`?` в каждом разделе): 9 статей `help/*.md`, справка навыков и уроки; поиск; свои статьи.
- **Настройка параметров**: карта параметров в профиле (`params`, `bus`), сценарии `params` и `tune`
  (копия «до», план «было → стало», «ДА», сверка, копия «после», откат); форма в браузере и мастере.
- **Навык Modbus RTU** (`skills/modbus_rtu`, выключен): приборы по RS-485 — термопреобразователи, регуляторы;
  учебная карта термопреобразователя, эталон настроек с сохранением адреса и скорости.
- **«Что помогло»**: после неудачи человек пишет одну фразу — в следующий раз подсказка первой.
- **Самопроверка** (`doctor [--heal]`, «Прибор» → «Самопроверка»): копии по SHA-256 в обоих местах, память,
  профили, навыки, лезвия, Штурман; починка копий из исправного места и правок из истории капота.
- Команды `params`, `tune --set`, `skills`, `doctor`, `help`; 46 автотестов (всего 149), эмулятор прибора Modbus.
### Изменено
- Ядро (только добавления): `core/params.py`, `core/skills.py`, `Conductor.read_params/tune`,
  навыки в реестре и перечитывание изменённых плагинов, `Plugin.voltage_check`, таблица `fixes`,
  `BackupStore.health/repair`. Прежние сценарии не менялись.
- Вкладка «Развитие» → «Навыки»; уроки — на отдельных страницах.

## 0.3.1 — 2026-11-14
### Добавлено
- Штурман знает новые инструменты: раздел «Подключить инструмент» на первом экране, 8 уроков
  (Bus Pirate 5, ARM/ST-Link, T48, AVR/USBasp, ESP, логический анализатор, сводка, binwalk_expect).
- Действие `capture` — замер sigrok прямо из браузера и мастера (в учебном режиме запрещён); метка «только приём».
- Подсказка «Какой инструмент подключить», когда инструментов нет; 7 автотестов (всего 103).

## 0.3.0 — 2026-11-14
### Добавлено
- Лезвия (все выключены по умолчанию): `probe_rs`, `openocd` (ARM по SWD/JTAG), `avrdude` (AVR, образ flash+EEPROM),
  `esptool` (ESP8266/ESP32, v4 и v5), `minipro` (T48/TL866II+), `bp5_i2c` (Bus Pirate 5, I2C EEPROM 24Cxx).
- `plugins/_common.py`: запрет опасных параметров (снятие защиты, стирание всего чипа, фьюзы, отключение сверки).
- Проверка `binwalk_expect`; замер логическим анализатором `python3 -m dirizher.extras.sigrok`.
- 9 профилей (STM32F103C8, ATmega328P, ESP32 4 МБ, 24C02 + общие), `system/99-dirizher-tools.rules`,
  `docs/INTEGRATIONS.md`, `docs/config-snippet-0.3.0.yaml`; 54 новых автотеста (всего 96).
### Изменено
- Ядро: своё напряжение адаптера у каждого плагина (`programmer_voltage` в настройках плагина).

## 0.2.0 — 2026-11-14
### Добавлено
- Интерфейсы поверх ядра (`dirizher/interface/`), ядро не менялось:
  - Штурман (`guide.yaml`, `guide.py`): вопросы «что будем делать?», подсказки «сейчас важно» по журналу,
    «что дальше?» после каждого итога, 19 уроков с примерами (работа и развитие), план из docs/STATUS.md.
  - Браузер (`web`): телефон, ПК, экран прибора; без интернета и сторонних библиотек; вход по коду,
    экран прибора — без кода; «ДА» вводится вручную и проверяется сервером; загрузка образа, скачивание дампов.
  - Текстовый мастер (`wizard`, а также запуск без команды): SSH, консоль USB-UART, маленькие экраны.
  - Конструктор профиля чипа: форма → проверка → YAML → черновик → включение после подтверждения человека.
- `system/dirizher-web.service`, `system/kiosk.sh` — служба и киоск для Raspberry Pi.
- Раздел `web` в config.yaml; 30 новых автотестов (всего 42).
- MANUAL: разделы 1.0, 1.5, 2.7, 2.8.

## 0.1.0 — 2026-11-14
### Добавлено
- Ядро «Дирижёра»: сценарий опознание → напряжение → копия «до» → диагностика → план → запись со сверкой → копия «после» → отзыв.
- Хранилище копий по SHA-256: только чтение, проверка целостности, зеркало.
- Память в SQLite: сеансы, события, снимки, эталоны, статистика рецептов; текстовые журналы.
- Обучение: черновики профилей для незнакомых чипов, эталоны, рейтинг рецептов по отзывам.
- Профили чипов и плат (сигнатура в дампе, уникальные области `preserve`), общий профиль SPI NOR.
- Плагин `flashrom_spi`; плагин `simulator` с учебными поломками.
- Команды: plugins, profiles, detect, run, history, show, feedback, reference, rollback, export, sim.
- 12 автотестов на симуляторе.
- `tools/bundle.py` — весь код одним файлом для проекта в приложении Claude.
- Документация: README, PRINCIPLES, docs/START, docs/MANUAL, docs/SESSION_PROMPT, docs/STATUS, CLAUDE.md.
